# Trhino GmbH – Website (Entwurf)

Open `index.html` in Chrome, Edge, Safari or Firefox. An internet connection is needed:
the 3D library (three.js) and the fonts load from public CDNs.

## Sections
1. Hero – 3D house that rises block by block, then is finished (render, tiled roof, windows, garden); "Massiv." headline, glass navigation
2. Leistungen – the house separates into its construction layers on scroll
3. Projekte – "Vom Modell zur Wirklichkeit": Siegburg, Hennef, Rheinbach
4. Ablauf – four steps with real Trhino photos
5. Kontakt – closing band with phone, email and address

## Files
- `index.html` – the whole page (styles and scripts inline)
- `img/` – optimised project and process photos (WebP)

For the best local preview, serve the folder with a small web server, e.g.
`npx serve .` or `python3 -m http.server`, then open the address it prints.
